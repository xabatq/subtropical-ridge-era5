# Result tables

Derived tables of the paper (copied from `<data>/outputs` after a full run). All trends are in degrees of |latitude| per decade (positive = poleward).

Copy the following files here before archiving the repository (a few MB in total):

* yearly ridge series: `peak_latitudes_by_year_masked.csv`, `calm_belt_min_speed_by_year.csv`, `levels_slp_ridge_by_year.csv`, `hadley_edge_by_year.csv`, `slp_high_centres_by_year.csv`, `ceres_era5_ridge_by_year.csv`, `clara_ridge_by_year.csv`
* trend tables: `main_trends_full_table.csv`, `enso_adjusted_trends.csv`, `basin_trends.csv`, `era5_subperiod_trends.csv`, `smoothing_sensitivity.csv`, `pdo_sam_adjusted_trends.csv`, `levels_slp_trends_ocean.csv`, `levels_slp_basin_trends.csv`, `slp_high_trends.csv`, `hadley_edge_trends.csv`, `hadley_vs_ridge_trends.csv`
* satellite comparisons: `ceres_vs_era5_cloud_ridge.csv`, `clara_vs_era5_cloud_ridge.csv`
* correlations and mean latitudes: `levels_slp_correlations.csv`, `levels_slp_mean_latitude.csv`, `hadley_vs_ridge_correlations.csv`, `hadley_vs_ridge_mean_latitude.csv`
* `enso_monthly_1966_2025.csv`, `climate_modes_monthly.csv` (index time series)

Each trend table contains the test-family size (`fdr_family_size`) next to the *q*-value. License: CC BY 4.0.
